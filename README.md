# Maître Jules Enock — Mèt Nòkyòk

PWA installable sur Android : mathématiques (formules, résolution de
problèmes sans IA, fractions, calculatrice), français (grammaire,
exercices, rédaction de lettres) et sciences sociales (géographie),
niveau fondamental.

Tous les fichiers sont à la racine (aucun sous-dossier), pour un envoi
sans problème depuis un téléphone.

## Déployer (identique au carnet de leçons)

1. Crée un **nouveau dépôt GitHub** séparé (ex. `maitre-jules-enock`).
2. Dézippe ce fichier sur ton téléphone.
3. Sur GitHub : **Add file → Upload files** → sélectionne **tous les
   fichiers** (pas de dossier) → commit.
4. **Settings → Pages** → source : branche `main`, dossier `/ (root)`.
5. Ouvre l'URL fournie, vérifie l'affichage.
6. Sur https://www.pwabuilder.com, colle l'URL, génère l'APK Android
   comme pour le premier carnet (Package ID, App name, clé de
   signature "Create new", Download Package).

## Contenu

- **Calculer** : addition, soustraction, multiplication, division,
  et une calculatrice à expression (ex. `(12 + 8) × 3`).
- **Formules** : 34 formules (quadrilatères, triangles, commerce —
  prix d'achat/vente/revient, jours travaillés —, partages égal /
  inégal / proportionnel, vitesse, moyenne...).
- **Résoudre** : colle un problème, l'app propose une formule par
  reconnaissance de mots-clés (sans IA) — à l'élève de confirmer
  quel nombre correspond à quelle variable, puis l'app calcule et
  montre la démarche.
- **Fractions** : addition, soustraction, multiplication, division et
  simplification, avec les étapes.
- **Grammaire** : référence organisée par catégories (natures,
  fonctions, accords, conjugaison, homophones, orthographe...).
- **Exercices** : banque de questions en grammaire, conjugaison,
  vocabulaire, orthographe, avec un formulaire pour en ajouter
  d'autres.
- **Lettre** : générateur de lettre (amicale, formelle, excuse,
  demande) à partir d'un formulaire guidé, imprimable/PDF.
- **Géo** : les 11 chapitres de sciences sociales demandés, en
  fiches de lecture.
- **Sciences** : le corps humain, les plantes, les états de la
  matière, les animaux, hygiène et santé.
- **Civisme** : symboles nationaux, droits de l'enfant, devoirs du
  citoyen, famille et respect, vie en communauté, valeurs morales.
- **Conversions** : longueur, masse et capacité (système métrique),
  avec la démarche de calcul.
- **Dictées** : 15 textes à écouter phrase par phrase (avec pauses,
  vitesse réglable, ponctuation dictée à voix haute), un bouton pour
  épeler n'importe quel mot à la demande, correction mot à mot, et un
  historique des scores conservé par dictée.

## Limites à connaître

- La grammaire et les exercices sont un contenu **écrit à l'avance**,
  pas généré automatiquement : la banque est volontairement solide
  mais pas infinie. Utilise le formulaire "Ajouter un exercice" pour
  l'enrichir au fil du temps.
- Le "Résoudre" fonctionne par reconnaissance de mots-clés, pas par
  compréhension réelle du langage : il peut se tromper sur une
  formulation inhabituelle, d'où l'étape de confirmation manuelle.
- Les dictées utilisent la synthèse vocale déjà installée sur le
  téléphone (voix française) : la qualité de lecture dépend de
  l'appareil, et une voix française doit être disponible.
