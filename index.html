📖 Formules de référence

  • Rectangle : P = 2 × (L + l), A = L × l
  • Carré : P = 4 × c, A = c × c
  • Triangle : P = a + b + c, A = (base × hauteur) ÷ 2
  • Parallélogramme : P = 2 × (a + b), A = base × hauteur
  • Losange : P = 4 × c, A = (D × d) ÷ 2
  • Trapèze : P = a + b + c + d, A = ((B + b) × h) ÷ 2
  • Vitesse : V = D ÷ T
  • Distance : D = V × T
  • Temps : T = D ÷ V
  • Moyenne : somme des valeurs ÷ nombre de valeurs
